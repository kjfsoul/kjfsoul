## Principles I reuse across projects

1. **Make the decision testable.** State the business question and the evidence that would count.
2. **Treat contracts and tests as first-class product features.** A polished output is not automatically valid.
3. **Keep agents within explicit boundaries.** Clear owners, tools, state, checkpoints and approval rules.
4. **Verify outcomes where they actually occur.** A green build or API response is not proof of publication, payment or adoption.
5. **Turn failures into reusable knowledge.** Regression cases, review signals, updated policies, better references and incident runbooks.
6. **Preserve the distinction between prototype, deployment and demonstrated impact.**
